# Bookratings

A React digital library where you can track books you've read, write short reviews, give each book a 1-5 star rating, and view a reading dashboard.

## Features

- Add books with title, author, genre, short review, and rating (1-5)
- Browse all books you've read
- Dashboard with:
  - Total books read
  - Average rating
  - Genre distribution
  - Rating distribution

## Run locally

```bash
npm install
npm run dev
```

## Quality checks

```bash
npm run lint
npm run build
```
